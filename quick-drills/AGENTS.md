# AGENTS.md — `quick-drills`

> See repo root `AGENTS.md` for the practice-session process and repo-wide
> conventions. This file covers only what's specific to this exercise.

**Scenario:** A set of small, independent, single-issue, cold-read drills
(`drill_01_*.py` … `drill_10_*.py`), each meant to take under five
minutes — rapid-cycle practice rather than one multi-issue critique.

**Shape:** Quick-drills — many small files in one folder, not a single
exercise.

**Files:** `drill_01_customer_orders.py` through
`drill_10_webhook_events.py`.

**Answer key:** `.answer-key.md` — one shared file covering every drill in
this folder.

**Notes:** Treat each file as its own exercise instance under the root
`AGENTS.md` process (orientation → the one issue → reasoning → close)
rather than expecting a prioritised list of several things per file.
Don't reveal which file maps to which issue before the user reads it
cold — that's the point of this folder.
